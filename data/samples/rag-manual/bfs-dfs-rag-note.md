# BFS 与 DFS 手动 RAG 测试资料

## BFS 的核心思想

BFS，也就是广度优先搜索，会从起点开始按层扩展节点。它通常使用 queue 保存待访问节点，因此每一层会先于下一层被处理。在无权图中，如果每条边的代价相同，BFS 第一次到达某个节点时，经过的边数就是从起点到该节点的最少边数。

## BFS 适合的场景

BFS 适合解决最短步数、层序遍历、状态空间按步数扩展的问题。例如迷宫最短路径、社交网络中的最短关系链，以及二叉树层序遍历。BFS 的主要代价是需要保存当前 frontier，因此空间复杂度可能较高。

## DFS 的核心思想

DFS，也就是深度优先搜索，会沿着一条路径尽可能深入，直到不能继续再回溯。DFS 常用递归调用栈或手动 stack 实现。它适合连通性判断、回溯搜索、拓扑结构分析，以及需要枚举路径的场景。

## BFS 与 DFS 的区别

BFS 更关注按层推进，通常能直接得到无权图的最短边数路径。DFS 更关注深入探索，空间占用在某些稀疏路径场景下更低，但不能保证第一次到达就是最短路径。选择 BFS 还是 DFS，要看问题是否强调最短步数、是否需要完整路径枚举，以及图的规模和内存限制。

## 易错点

不要把 BFS 和 DFS 都只理解成“遍历所有点”。BFS 的关键是 queue 和层次，DFS 的关键是 stack/递归和回溯。无权最短路径一般优先 BFS；如果题目要求枚举所有可能路径或做回溯选择，通常优先 DFS。
