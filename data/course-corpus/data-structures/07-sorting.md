# 第 7 章 排序

## 核心概念

排序算法可以比较稳定性、是否原地、最坏复杂度和额外空间。冒泡排序、选择排序和插入排序适合小规模或近乎有序数据，典型复杂度为 O(n^2)。

归并排序采用分治，复杂度为 O(n log n)，但通常需要额外数组；快速排序通过 pivot 分区，平均 O(n log n)，最坏可能为 O(n^2)；堆排序利用堆，复杂度为 O(n log n) 且可以原地完成。

## 例题与练习

练习：实现插入排序和归并排序，构造快速排序的最坏输入，并比较稳定排序与不稳定排序的应用场景。

## 易错点

平均复杂度不能代替最坏保证；快速排序的 pivot 选择影响退化；稳定性只有在相等键还要保留原顺序时才重要。

## Python 代码案例

```python
def merge_sort(values):
    if len(values) <= 1:
        return values
    middle = len(values) // 2
    left = merge_sort(values[:middle])
    right = merge_sort(values[middle:])
    result = []
    while left and right:
        result.append((left if left[0] <= right[0] else right).pop(0))
    return result + left + right
```

## 知识点拆解

### 1. 排序评价指标

稳定排序在相等键之间保持原有顺序；原地排序只使用常数级或受限额外空间；自适应排序会利用输入已经接近有序这一事实。工程选择不能只看平均时间，还要考虑最坏保证、数据规模、内存和稳定性。

### 2. 简单排序

冒泡排序通过相邻交换把较大元素逐步推到末尾，加入提前退出后对有序数据较快。选择排序每轮选择最小元素，交换次数少但比较次数仍为 O(n²)。插入排序把当前元素插入已排序前缀，对近乎有序数据非常有效。

### 3. 高效排序

归并排序把序列分成两半，递归排序后线性合并，稳定且复杂度 O(n log n)。快速排序原地分区，平均 O(n log n)，应通过随机 pivot 或三数取中降低退化概率。堆排序利用最大堆反复取出最大值，最坏 O(n log n)。

## 例题详解

例题一：插入排序的循环不变量是“每轮开始时，当前位置左侧已经有序”。把当前值保存为 key，从右向左移动大于 key 的元素，再写回 key。

例题二：归并两个有序序列时，比较两个首元素，把较小者写入结果并只移动对应指针。若一侧耗尽，直接拼接另一侧剩余元素。

例题三：快速排序分区后，pivot 左侧都不大于 pivot，右侧都不小于 pivot；递归处理两个区间。若每次都选到极值，递推式退化为 T(n)=T(n-1)+O(n)。

## 练习题

1. 为插入排序增加提前退出，并说明何时达到 O(n)。
2. 实现稳定的归并排序，统计比较次数。
3. 比较快速排序、归并排序和堆排序的稳定性与额外空间。

## 参考答案

1. 如果一轮没有发生交换，说明序列已经有序，可以直接结束；最好情况为 O(n)。
2. 合并时相等元素优先取左侧元素，才能保持原序列中的相对顺序。
3. 归并排序稳定但需要 O(n) 辅助空间；快速排序通常不稳定且平均原地；堆排序不稳定但最坏 O(n log n) 且可原地。

## 易错点复盘

平均 O(n log n) 不是快速排序的最坏保证；稳定性与是否原地是不同指标；归并时相等元素的选择会影响稳定性；排序复杂度要说明输入是否近乎有序。

## 实验任务

准备随机、升序、降序和大量重复值四种输入，比较五种排序的比较次数、交换次数和运行时间，并解释实验结果为什么与理论最好/平均/最坏复杂度一致或不一致。

## 课堂小结

排序选择是多目标权衡：数据量小且近乎有序时插入排序很有竞争力；要求稳定且可接受额外空间时选择归并排序；要求原地和平均性能时可以选择快速排序；要求最坏 O(n log n) 保证时可以选择堆排序。报告必须区分比较次数、交换次数和辅助空间。
