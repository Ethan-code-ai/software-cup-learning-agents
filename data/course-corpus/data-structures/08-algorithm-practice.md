# 第 8 章 综合应用与算法实践

## 核心概念

分治把问题拆成相同形式的子问题，贪心每一步选择当前最优但需要证明全局正确性，动态规划利用重叠子问题和最优子结构保存状态，回溯则系统枚举选择并剪枝。

代码审查要同时检查数据结构选择、循环边界、递归终止、异常输入和复杂度。综合实践应经历问题建模、结构选择、算法实现、单元测试和结果解释。

## 例题与练习

练习：用动态规划解决爬楼梯，用贪心解决区间调度，用 BFS 解决网格最短路，并为每个实现写边界测试和复杂度说明。

## 易错点

“能运行”不等于“复杂度合理”；贪心策略必须有正确性依据；测试不能只覆盖正常输入，还要覆盖空数据、单元素和重复元素。

## Python 代码案例

```python
def climb_stairs(steps):
    previous, current = 1, 1
    for _ in range(steps):
        previous, current = current, previous + current
    return previous
```

## 知识点拆解

### 1. 分治

分治包含分解、解决和合并三个阶段。归并排序是典型例子：把数组拆成左右两部分，递归排序，再合并两个有序结果。使用分治前要确认子问题与原问题结构相同，并估算合并成本。

### 2. 贪心

贪心每次选择当前看起来最优的方案，但必须证明局部选择不会破坏全局最优。区间调度按结束时间升序选择可以获得最多不重叠区间；按开始时间或区间长度排序并不总是正确。

### 3. 动态规划

动态规划需要识别状态、转移、初始条件和计算顺序。爬楼梯的状态 `dp[i]` 表示到达第 i 阶的方法数，转移为 `dp[i]=dp[i-1]+dp[i-2]`。如果只依赖前两项，可以把空间从 O(n) 优化到 O(1)。

### 4. 工程化算法实践

完整实现应包括输入校验、核心算法、复杂度说明、单元测试、异常处理和可解释输出。数据结构选择必须与访问模式匹配，不能只追求代码短小。

## 例题详解

例题一：区间调度。将区间按结束时间排序，依次选择开始时间不早于上一个结束时间的区间。交换论证表明，最早结束的可行区间不会比任何其他首选方案差。

例题二：0/1 背包。`dp[i][w]` 表示前 i 件物品在容量 w 下的最大价值，转移为不选第 i 件或选择第 i 件。若压缩为一维数组，容量必须逆序遍历，避免同一物品被重复使用。

例题三：网格最短路。将网格位置看成顶点，四个方向看成边，用 BFS 维护距离。遇到墙或越界时跳过，首次到达终点即可返回。

## 练习题

1. 使用分治求数组最大子段和，并比较暴力解法。
2. 证明区间调度按结束时间选择的贪心策略正确。
3. 实现 0/1 背包的一维动态规划，并测试容量为 0 和物品为空。
4. 为网格 BFS 增加路径恢复和不可达提示。

## 参考答案

1. 分治递归计算左半、右半和跨越中点的最大值，复杂度 O(n log n)。
2. 对任意最优方案，用结束最早的区间替换其第一个区间不会减少后续可选空间，因此可以安全地做局部选择。
3. 初始化 dp 为 0，物品容量从大到小更新 `dp[w] = max(dp[w], dp[w-weight] + value)`。
4. 为每个首次访问位置记录 parent，终点不可达时返回空路径并给出明确原因。

## 易错点复盘

贪心不等于“每一步随便选最大值”；动态规划状态必须覆盖所有影响未来的变量；一维背包正序更新会错误地重复使用物品；BFS 必须在入队时标记 visited，避免重复入队。

## 实验任务

选择一个综合问题，提交问题建模、数据结构选择、算法伪代码、Python 实现、复杂度分析和至少 8 个测试用例。测试必须覆盖正常、边界、空输入、重复数据、不可达和大规模输入。

## 课堂小结

综合实践要求把抽象知识落到可验证的软件行为：先定义输入输出和约束，再选择数据结构和算法，最后用测试与复杂度分析证明实现满足要求。一个没有边界处理、没有失败提示、没有测试记录的程序，即使样例能运行，也不能算完成的算法实践。
