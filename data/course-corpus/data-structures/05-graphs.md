# 第 5 章 图与图遍历

## 核心概念

图由顶点和边组成，可以是有向图或无向图，也可以带权。邻接矩阵适合稠密图并支持 O(1) 判断边，邻接表更节省稀疏图空间。

BFS 使用 queue 按层扩展，第一次到达无权图结点时得到最少边数；DFS 使用递归栈或显式 stack 深入探索，适合连通性、回溯和拓扑结构分析。带权最短路径需要根据边权选择合适算法。

## 例题与练习

例题：迷宫最短步数使用 BFS，寻找所有路径可使用 DFS 回溯。练习：实现邻接表、BFS、DFS 和无权图最短路径。

## 易错点

不能因为 DFS 先到达某结点就断言路径最短；遍历时要及时标记 visited，避免无向图重复走边；图的复杂度应同时考虑 V 和 E。

## Python 代码案例

```python
from collections import deque

def bfs(graph, start):
    distance = {start: 0}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph.get(node, []):
            if neighbor not in distance:
                distance[neighbor] = distance[node] + 1
                queue.append(neighbor)
    return distance
```

## 知识点拆解

### 1. 图的模型与存储

图可以表示为 G=(V,E)，V 是顶点集合，E 是边集合。邻接矩阵空间为 O(|V|²)，适合稠密图；邻接表空间为 O(|V|+|E|)，适合稀疏图。无向图一条边在两个顶点的邻接表中各出现一次。

### 2. BFS 与 DFS

BFS 使用队列维护 frontier，并记录距离和前驱，因此可以恢复无权最短路径。DFS 沿一条分支深入，返回时回溯；可用于连通分量、环检测、拓扑排序和路径枚举。两者遍历复杂度通常为 O(|V|+|E|)。

### 3. 最短路径选择

无权图使用 BFS；边权非负时可以使用 Dijkstra；允许负边时需要 Bellman-Ford；所有点对距离可考虑 Floyd-Warshall。算法选择取决于边权约束、图规模和是否需要单源或全源结果。

## 例题详解

例题一：迷宫最短路。把每个可走位置作为顶点，相邻位置作为边，从起点 BFS。第一次访问终点时的距离就是最少步数。

例题二：判断无向图是否有环。DFS 访问邻居时，如果邻居未访问就递归；如果邻居已访问且不是当前结点的父结点，则发现环。

例题三：拓扑排序只适用于有向无环图。可以用入度为 0 的队列，也可以用 DFS 的三色标记。若处理结点数小于 V，则图中存在环。

## 练习题

1. 实现邻接表和邻接矩阵，并比较判断一条边是否存在的复杂度。
2. 输出 BFS 得到的最短路径，而不只是最短距离。
3. 实现 Kahn 拓扑排序并检测课程先修关系中的环。

## 参考答案

1. 邻接矩阵查询 O(1)，邻接表查询需要扫描某顶点的邻接边，复杂度为 O(degree(v))。
2. BFS 首次访问邻居时记录 parent，终点出现后沿 parent 反向回溯再翻转列表。
3. 先统计入度，把入度为 0 的顶点放入队列；删除边并更新入度，最终输出数量不足 V 即为有环。

## 易错点复盘

DFS 的首次到达不保证最短；无向边要避免把父结点误判为环；遍历非连通图时要从每个未访问顶点重新启动；复杂度不能只写 O(V)，还要计入 E。

## 实验任务

构造稀疏图和稠密图，分别用邻接矩阵与邻接表执行 BFS。记录内存占用、边查询次数和遍历时间，解释两种表示在不同密度下的取舍。

## 课堂小结

图问题的第一步是明确顶点和边的含义，第二步是选择表示方式，第三步才是选择 BFS、DFS 或最短路径算法。BFS 的“第一次到达最短”只在边权相同的前提下成立；DFS 的优势是探索和回溯，不是自动产生最短路径。所有图遍历都必须设计 visited 规则。
