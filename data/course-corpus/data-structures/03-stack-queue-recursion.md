# 第 3 章 栈、队列与递归

## 核心概念

栈遵循 LIFO（后进先出），基本操作是 push、pop 和 peek，常用于函数调用、括号匹配、表达式求值和 DFS。队列遵循 FIFO（先进先出），基本操作是 enqueue 和 dequeue，常用于任务调度、消息缓冲和 BFS。

循环队列使用取模运算复用数组空间。递归必须包含递归基和规模缩小步骤；回溯在递归返回时撤销当前选择，适合排列、组合和迷宫搜索。

## 例题与练习

例题：判断括号是否匹配时，用栈保存左括号；按层访问树时，用队列保存下一批结点。练习：实现最小栈、循环队列和全排列回溯。

## 易错点

不能把 BFS 的队列写成栈；递归没有递归基会无限调用；回溯撤销状态必须和做出选择严格对应。

## Python 代码案例

```python
from collections import deque

def first_unique_window(values, window):
    queue = deque()
    counts = {}
    for value in values:
        queue.append(value)
        counts[value] = counts.get(value, 0) + 1
        while queue and counts[queue[0]] > 1:
            counts[queue.popleft()] -= 1
    return list(queue)[-window:]
```

## 知识点拆解

### 1. 栈的抽象数据类型

栈只允许在一端操作。push、pop 和 peek 都应为 O(1)。数组实现需要维护 top 下标，链表实现通常在头部插入和删除。函数调用栈保存局部变量、返回地址和参数，因此递归深度过大可能触发栈溢出。

### 2. 队列与循环队列

队列的核心约束是 FIFO。数组队列如果每次出队都整体搬移，会退化为 O(n)；循环队列用 `(index + 1) % capacity` 移动下标，并用 size 区分空和满。双端队列允许两端插入和删除，可用于滑动窗口问题。

### 3. 递归与回溯模板

递归函数必须回答三个问题：什么时候停止、如何缩小问题、如何组合子问题答案。回溯在路径上做选择，递归深入，返回时撤销选择。状态恢复遗漏会污染后续分支，是回溯题最常见的 bug。

## 例题详解

例题一：括号匹配。遇到左括号入栈，遇到右括号时检查栈顶类型是否匹配并弹出，扫描结束后栈必须为空。时间复杂度 O(n)，空间复杂度 O(n)。

例题二：用两个栈实现队列。输入栈负责入队，输出栈负责出队；只有输出栈为空时才把输入栈全部转移过去。单次操作可能 O(n)，但均摊复杂度为 O(1)。

例题三：全排列回溯。每层选择一个尚未使用的元素，递归返回后取消 used 标记。n 个元素共有 n! 个排列，输出本身决定了时间下界。

## 练习题

1. 实现支持 get_min 的最小栈，要求 push、pop、get_min 均为 O(1)。
2. 实现循环队列，并测试空队列、满队列和反复出入队。
3. 使用回溯生成 1 到 n 的所有排列，并统计递归节点数。

## 参考答案

1. 额外维护一个保存当前最小值的栈，每次 push 保存 `min(value, current_min)`。
2. 维护 front、rear 和 size；入队后 rear 取模，出队后 front 取模。
3. 每层遍历所有未使用元素，递归返回时恢复 used 和当前路径，叶子节点复制一份答案。

## 复杂度与边界

栈和队列的“操作 O(1)”不代表所有应用 O(1)，例如遍历整个结构仍然需要 O(n)。递归题要测试 n=0、n=1、重复元素、无解和深度上限；队列还要测试容量为 1 的情况。

## 实验任务

比较列表、`collections.deque` 和链表实现队列的入队/出队性能。要求解释为什么列表头部 `pop(0)` 会移动大量元素，而 deque 能够稳定地完成两端操作。

## 课堂小结

栈、队列和递归分别体现了后进先出、先进先出和自相似问题分解。看到“最近状态优先”通常想到栈，看到“按到达顺序或层次处理”通常想到队列，看到“枚举选择并撤销”通常想到回溯。所有递归实现都应先写终止条件，再写状态变化。
