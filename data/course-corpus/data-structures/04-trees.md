# 第 4 章 树与二叉树

## 核心概念

树由结点和边组成，根结点没有父结点，叶结点没有孩子。树的高度决定了很多递归操作的最大深度。二叉树的每个结点最多有两个孩子，满二叉树和完全二叉树具有特殊结构。

前序遍历顺序是根、左、右；中序是左、根、右；后序是左、右、根；层序遍历按深度逐层访问，通常使用队列。对二叉搜索树进行中序遍历可以得到有序序列。

## 例题与练习

例题：由前序和中序序列可以递归恢复二叉树。练习：实现四种遍历，计算树高，并判断一棵树是否为平衡树。

## 易错点

不要混淆遍历的“访问根结点时机”；层序遍历需要区分当前层和下一层；二叉树不等于二叉搜索树。

## Python 代码案例

```python
from collections import deque

def level_order(root):
    if root is None:
        return []
    result, queue = [], deque([root])
    while queue:
        node = queue.popleft()
        result.append(node.value)
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
    return result
```

## 知识点拆解

### 1. 树的基本术语

结点的子树数量称为度，根到最深叶子的边数称为树高。深度和高度都以边数或层数为单位，但必须在题目中统一约定。森林是若干棵互不相交的树，树可以通过孩子兄弟表示法转换为二叉结构。

### 2. 二叉树性质

第 i 层最多有 2^i 个结点，高度为 h 的二叉树最多有 2^(h+1)-1 个结点。完全二叉树适合使用数组存储：下标 i 的左孩子为 2i+1，右孩子为 2i+2。满二叉树的每个非叶结点都有两个孩子。

### 3. 遍历与重建

前序用于先处理根，常见于复制树；中序用于得到二叉搜索树的有序序列；后序适合先处理子树再删除根；层序适合按距离或层次处理。给定前序和中序，前序首元素是根，在中序中定位根后即可递归划分左右子树。

## 例题详解

例题一：求二叉树高度。空树高度为 -1 或 0，取决于约定；非空树高度为 `1 + max(left_height, right_height)`。递归访问每个结点一次，时间复杂度 O(n)，递归栈空间 O(h)。

例题二：判断两棵树是否相同。同步比较根值，再递归比较左右子树；一棵为空而另一棵非空时立即返回 False。复杂度为 O(n)。

例题三：层序遍历的每轮可以记录当前队列长度，先保存该长度，再弹出这一层的所有结点，由此得到二维的按层结果。

## 练习题

1. 非递归实现前序、中序和后序遍历。
2. 根据前序和中序序列重建二叉树。
3. 判断二叉树是否平衡，并返回每个结点的高度。

## 参考答案

1. 前序使用栈；中序不断沿左链入栈再访问；后序可使用两个栈，或在单栈中记录最近访问结点。
2. 用哈希表保存中序下标，递归函数接收前序和中序边界，根结点把序列分成左右部分。
3. 后序计算高度，若子树不平衡或高度差超过 1，返回失败标记，避免重复计算。

## 易错点复盘

二叉树不一定有序；完全二叉树和满二叉树定义不同；层序遍历使用队列而不是栈；递归重建时边界区间必须保持前序和中序长度一致。

## 实验任务

随机生成不同高度的二叉树，比较四种遍历的递归和迭代实现。记录访问序列、最大栈深度和运行时间，并用退化链状树验证空间复杂度随高度变化。

## 课堂小结

树算法的关键变量通常是高度 h，而不是只看结点数量 n。平衡树的 h 接近 log n，退化树的 h 可能达到 n。遍历题要先确定访问顺序，再选择递归或显式栈；需要层次信息时使用队列，并在测试中覆盖空树、单支树、完全树和重复值。
