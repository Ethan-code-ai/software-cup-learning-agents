# 第 1 章 绪论与复杂度分析

## 核心概念

数据结构研究数据的逻辑关系、存储表示和操作算法。分析算法时要关注输入规模 n 增长后的时间复杂度和空间复杂度。常见量级包括 O(1)、O(log n)、O(n)、O(n log n) 和 O(n^2)。

渐进记号 O 描述上界，Ω 描述下界，Θ 描述紧确界。比较两个算法时，应先说明输入规模、最坏或平均情况，再比较主导项。

递归算法通常可以写成递推式。例如二分查找满足 T(n)=T(n/2)+O(1)，因此时间复杂度是 O(log n)；归并排序满足 T(n)=2T(n/2)+O(n)，因此是 O(n log n)。

## 例题与练习

例题：双重循环分别遍历 n 和 n/2 个元素，基本操作数量与 n^2 同阶，所以复杂度为 O(n^2)。练习：分析线性查找、二分查找和递归阶乘的复杂度。

## 易错点

不要把常数倍、低阶项和不同输入规模混在一起比较；递归复杂度也不能只看递归深度，还要乘以每层工作的数量。

## Python 代码案例

```python
def binary_search(items, target):
    left, right = 0, len(items) - 1
    while left <= right:
        middle = (left + right) // 2
        if items[middle] == target:
            return middle
        if items[middle] < target:
            left = middle + 1
        else:
            right = middle - 1
    return -1
```

## 知识点拆解

### 1. 算法效率模型

输入规模用 n 表示。基本操作包括比较、赋值、算术运算和数组访问。分析时先统计循环执行次数，再保留增长最快的项。例如 `3n^2 + 4n + 7` 的渐进阶为 Θ(n^2)。空间复杂度既包括显式申请的数组，也包括递归调用栈。

### 2. 常见复杂度对比

| 复杂度 | 典型算法 | 规模增长后的表现 |
|---|---|---|
| O(1) | 数组下标访问 | 与 n 无关 |
| O(log n) | 二分查找 | 每轮缩小一半 |
| O(n) | 顺序查找 | 扫描一次数据 |
| O(n log n) | 归并排序 | 分层处理并合并 |
| O(n^2) | 冒泡排序 | 两层相互比较 |

### 3. 最好、平均和最坏情况

顺序查找成功时可能第一项就命中，最好情况是 O(1)；目标不存在时必须扫描全部元素，最坏情况是 O(n)。如果没有特别说明，算法题通常优先讨论最坏时间复杂度，因为它给出稳定的性能上界。

## 例题详解

例题一：分析下面代码的复杂度。

```python
total = 0
for i in range(n):
    j = 1
    while j < n:
        total += 1
        j *= 2
```

外层执行 n 次，内层每次把 j 乘 2，执行 ⌈log₂n⌉ 次，因此总复杂度为 Θ(n log n)，额外空间为 O(1)。

例题二：递归函数每次把问题分成两个规模减半的子问题，并在线性时间合并。递推式为 `T(n)=2T(n/2)+cn`，每一层工作量都是 cn，共有 log n 层，因此 T(n)=Θ(n log n)。

## 练习题

1. 分析三重循环中最内层步长每次乘 2 的时间复杂度。
2. 说明为什么访问 Python list 的下标是 O(1)，而在链表中按下标访问是 O(n)。
3. 写出线性搜索和二分搜索的适用条件，并比较它们的空间复杂度。

## 参考答案

1. 两个线性循环和一个对数循环相乘，复杂度为 O(n²log n)。
2. list 通过连续地址计算元素位置；链表必须从头结点逐个沿 next 指针移动。
3. 二分搜索要求数据有序，迭代实现额外空间为 O(1)；线性搜索不要求有序，但最坏时间为 O(n)。

## 实验任务

随机生成不同规模的有序数组，分别运行线性查找和二分查找，记录比较次数。要求输出 n、算法名称、是否命中、比较次数，并用实验结果解释理论复杂度。边界测试至少包括空数组、单元素、首元素、尾元素和不存在的目标。

## 课堂小结

本章的核心不是背诵复杂度表，而是能够从代码结构反推出操作次数。遇到循环先看每层迭代范围，遇到递归先写递推式，遇到数据结构操作则区分访问、搜索、插入和删除。最终报告必须同时给出时间复杂度、空间复杂度、最好情况和最坏情况。
