# A3 学生智能学习系统：评委安装、运行与云端访问说明

本文保留参赛安装包的历史说明，其中根目录脚本和云端地址不作为当前源码版的运行保证。从本仓库安装与运行，请先阅读 [源码版安装与运行指南](README.md)，使用 `scripts/` 下实际提供的入口。

## 1. 项目访问方式

本项目已经完成云端部署，评委可以直接访问：

**https://ms7.fun**

云端页面名称为 **A3 Student Console**。截至 **2026-07-20**，该地址可以正常返回页面，评委不需要在本地安装 Python、Node.js 或配置 LLM API Key 即可查看云端作品。

云端演示优先用于快速体验完整 Web 作品；本地安装包用于离线复核、源码审查和部署过程复现。

## 2. 本地运行环境

本地运行需要 Windows 10/11、PowerShell、Python 和 Node.js：

| 软件 | 要求 | 用途 |
|---|---|---|
| Python | **3.11 或更高版本** | 运行 FastAPI 后端和本地数据处理逻辑 |
| Node.js | **20.19+ 或 22.12+** | 运行 React/Vite 前端 |
| npm | 随 Node.js 安装 | 安装前端依赖 |
| 浏览器 | Edge、Chrome 或 Chromium | 访问本地 Web 页面 |

## 3. 一键安装

将“作品安装/可执行文件”压缩包解压到没有中文和空格的目录，例如：

```text
C:\A3StudentSystem
```

在该目录打开 PowerShell，执行：

```powershell
.\install.ps1
```

安装脚本会自动完成：

1. 检查 Python 和 Node.js 版本。
2. 创建项目专用 Python 虚拟环境 `.venv`。
3. 安装 FastAPI、Uvicorn、SQLite、文档解析等 Python 依赖。
4. 使用 `npm ci` 安装前端依赖。
5. 创建本地演示数据目录 `data`。

如果 PowerShell 禁止执行脚本，可以只对当前窗口临时放开脚本执行权限：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

## 4. 本地启动

安装完成后执行：

```powershell
.\run.ps1
```

启动成功后，在浏览器打开：

```text
http://127.0.0.1:5173
```

系统默认使用：

- **SQLite 演示数据库**：`data/demo.sqlite3`
- **本地 rule-based 模式**：无需联网和 API Key
- **后端地址**：`http://127.0.0.1:8000`
- **前端地址**：`http://127.0.0.1:5173`

停止运行时，在 PowerShell 窗口按：

```text
Ctrl+C
```

如果 `5173` 端口已被占用，可以自动选择其他前端端口：

```powershell
.\run.ps1 -AutoSelectFrontendPort
```

脚本会在终端输出实际访问地址。

## 5. 配置 LLM API 和大模型

### 5.1 配置原则

LLM 配置采用 **OpenAI-compatible API** 形式，主要需要四项参数：

| 参数 | 含义 | 示例 |
|---|---|---|
| `LLM_PROVIDER` | 模型服务类型 | `openai_compatible` |
| `LLM_BASE_URL` | API 服务地址 | `https://api.deepseek.com` |
| `LLM_MODEL` | 模型名称 | `deepseek-chat` |
| `LLM_API_KEY` | API 密钥 | 由模型服务商提供 |

API Key 只应保存在评委本机的当前 PowerShell 会话或部署服务器的密钥配置中，不要写入源码、ZIP 包、README、截图或 Git 提交。

### 5.2 使用命令行参数启动 LLM

以 DeepSeek 为例：

```powershell
.\run.ps1 `
    -EnableLlm `
    -LlmProvider "openai_compatible" `
    -LlmBaseUrl "https://api.deepseek.com" `
    -LlmModel "deepseek-chat" `
    -LlmApiKey "在此填入评委自己的 API Key"
```

启用后，系统会为 `Tutor`、`Resource`、`Evaluator`、`ProfileUpdater`、`ProfileBuilder`、`Planner` 和 `Quiz` 等 Agent 打开 LLM 调用开关。

### 5.3 使用环境变量启动 LLM

也可以在当前 PowerShell 会话中设置环境变量。直接输入包含真实密钥的命令仍可能进入终端历史记录，请按本机的凭据管理方式处理：

```powershell
$env:LLM_PROVIDER = "openai_compatible"
$env:LLM_BASE_URL = "https://api.deepseek.com"
$env:LLM_MODEL = "deepseek-chat"
$env:LLM_API_KEY = "在此填入评委自己的 API Key"

.\run.ps1 -EnableLlm
```

使用其他 OpenAI-compatible 服务时，只需替换 `LLM_BASE_URL` 和 `LLM_MODEL`。服务商如果要求不同的模型名称，应以其控制台显示的模型 ID 为准。

### 5.4 LLM 失败时的回退行为

系统默认保留 **rule-based fallback**。当 API Key 无效、网络不可用、模型服务超时或模型返回格式不符合要求时，系统会回退到规则式流程，保证基础演示链路仍可运行。

因此，评委可以先直接体验 `https://ms7.fun` 或本地默认模式，再根据需要配置自己的 LLM API 进行增强体验。

## 7. 常见问题

### 找不到 Python

安装 Python 3.11 或更高版本，并在安装程序中勾选 **Add Python to PATH**，重新打开 PowerShell 后再执行 `install.ps1`。

### 找不到 npm

安装 Node.js 20.19+ 或 22.12+，重新打开 PowerShell 后执行：

```powershell
npm --version
```

能够输出版本号后，再执行 `install.ps1`。

### 端口被占用

使用：

```powershell
.\run.ps1 -AutoSelectFrontendPort
```

后端端口如有冲突，可以指定其他后端端口：

```powershell
.\run.ps1 -BackendPort 8010 -AutoSelectFrontendPort
```

### LLM 调用失败

检查以下内容：

1. `LLM_BASE_URL` 是否为服务商要求的 API 根地址。
2. `LLM_MODEL` 是否为服务商实际支持的模型 ID。
3. `LLM_API_KEY` 是否有效且仍有额度。
4. 当前网络是否可以访问模型服务。

即使 LLM 配置失败，也可以删除 `-EnableLlm`，使用默认本地 rule-based 模式继续演示。

## 8. 评委推荐操作顺序

1. 直接访问 **https://ms7.fun**，快速体验云端作品。
2. 如需复核本地部署，解压安装包并执行 `install.ps1`。
3. 执行 `run.ps1`，访问 `http://127.0.0.1:5173`。
4. 默认不配置 API Key，先验证基础功能。
5. 如需观察真实大模型效果，再按本文第 5 节配置评委自己的 LLM API。
